## Chunk 1: Reset `converged.json` on champion change (Critical — system-blocking bug)

**File:** `scripts/pine-autoresearch.mjs` lines 3123–3137

**Problem:** When an external champion change is detected, the scheduler state is fully reset (tabu, stagnation, streaks), but `converged.json` is NOT deleted. If the system previously converged, the convergence marker persists and all future cycles are skipped despite the new champion. This permanently blocks the research loop.

**Fix:** After the champion-change reset block writes the new scheduler state, attempt to delete `converged.json`. Use a try/catch to handle the case where the file doesn't exist.

**Changes:**

After line 3136 (`await writeSchedulerState(schedulerStatePath, loadedSchedulerState);`), insert:

```js
    try {
      await fs.unlink(path.join(config.researchRoot, 'state', 'converged.json'));
    } catch { /* no convergence marker to remove */ }
```

**Verification:**
- Run full test suite: `node --test tests/pine-autoresearch.test.mjs`
- Manual: set up a converged state + change champion fingerprint, run a cycle, confirm it does NOT short-circuit.

## Chunk 2: Fix `buildMetadata` nested metadata shape (Critical — manifest bloat)

**File:** `scripts/lib/pine-track-generators.mjs` lines 105–124

**Problem:** `buildMetadata` returns an object that spreads `metadata` to top-level AND nests the full `metadata` object (which includes `config`) as `.metadata`. This causes `config` to be serialized twice per variant in manifests — once at `variant.config` and once at `variant.metadata.config`.

**Confirmed safe:** Zero references to `.metadata.config` in the entire codebase. All 6 spread sites (`pine-autoresearch.mjs:1012`, `pine-search-policy.mjs:397`, `pine-exit-generators.mjs:195`, `pine-global-search.mjs:315`, `pine-lane-novelty.mjs:216`, `pine-tuner.mjs:13`) only use metadata for provenance/fingerprint fields, never `config`.

**Fix:** Remove `config` from the inner `metadata` object. Add `config` explicitly to the return statement so it remains at the top level.

**Changes:**

1. In `scripts/lib/pine-track-generators.mjs`, line 116 — remove `config` from the `metadata` object literal:

```js
// BEFORE (lines 105-117):
const metadata = {
  variantId: `${String(family || trackId)}-${String(index + 1).padStart(2, '0')}`,
  family,
  lane,
  patch: clone(patch),
  patchFingerprint,
  patchFingerprintVersion: LANE_PATCH_FINGERPRINT_VERSION,
  sharedKeys: patchKeys.filter((key) => shared.includes(key)),
  ownKeys: patchKeys.filter((key) => own.includes(key)),
  temperature,
  tabuSkipped,
  config,
};

// AFTER:
const metadata = {
  variantId: `${String(family || trackId)}-${String(index + 1).padStart(2, '0')}`,
  family,
  lane,
  patch: clone(patch),
  patchFingerprint,
  patchFingerprintVersion: LANE_PATCH_FINGERPRINT_VERSION,
  sharedKeys: patchKeys.filter((key) => shared.includes(key)),
  ownKeys: patchKeys.filter((key) => own.includes(key)),
  temperature,
  tabuSkipped,
};
```

2. In the return statement (lines 119-124), add `config` explicitly at top level since it's no longer spread from `metadata`:

```js
// BEFORE:
return {
  ...metadata,
  patchFingerprint,
  patchFingerprintVersion: LANE_PATCH_FINGERPRINT_VERSION,
  metadata,
};

// AFTER:
return {
  ...metadata,
  config,
  patchFingerprint,
  patchFingerprintVersion: LANE_PATCH_FINGERPRINT_VERSION,
  metadata,
};
```

**Verification:**
- Run existing test: `node --test tests/pine-track-generators.test.mjs`
- The test at line 1051 asserts `typeof variant.metadata.patchFingerprint === 'string'` — still passes.
- `variant.config` still accessible (explicitly in return).
- `variant.metadata.config` is now `undefined` (no consumers exist).

**Problem:** The function `collectRecentRejectedCandidateFingerprints` is defined but never called. It was replaced by `collectRecentRejectedCandidateTabuEntries` (line 2481).

**Fix:** Delete the function definition (lines 2452–2465).

**Changes:**

Remove:
```js
async function collectRecentRejectedCandidateFingerprints(config, limit = 16) {
  const files = (await listManifestFiles(config)).slice(-Math.max(0, limit));
  const fingerprints = [];
  for (const fileName of files) {
    try {
      const manifest = await readJson(path.join(manifestsDir(config), fileName));
      const fingerprint = inferRejectedCandidateFingerprint(manifest);
      if (fingerprint) fingerprints.push(fingerprint);
    } catch {
      // Ignore corrupt or concurrently-pruned manifests; current cycle can still proceed.
    }
  }
  return [...new Set(fingerprints)];
}
```
